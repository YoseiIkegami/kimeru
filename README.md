# KIMERU

少人数で決めたいことを、決定カードと既存チャットへ送る依頼文にする小さなWebツールです。

## 試す

Node.js 22.18以上。

```bash
npm install
npm run dev
```

決めたいこと、選択肢2〜6個、締切、参加者名を入力し、決定カードまたは依頼文をコピーします。入力はブラウザ内の一時メモリだけで扱い、ページを閉じると消えます。

## 検証

```bash
npm run lint
npm test
npm run build
```

仮説：少人数の予定・購入・役割分担で、決定内容を一問と選択肢に絞り、回答依頼文まで一枚にできれば、作成者はチャットを往復するより速く合意を始められる。

対象は、直近7日以内に少人数で予定・購入・役割を決める人です。利用継続、顧客反応、課金可能性は未確認です。

共有リンク上の集計、ログイン、通知、匿名投票、保存、決済は対象外です。既存の投票・フォームとの差も検証前です。
